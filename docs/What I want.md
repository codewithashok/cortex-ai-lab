# AI Learning Project Instructions

## Background

I am a frontend developer with experience in React, Next.js, JavaScript, and TypeScript.

Recently, I practiced:

* CRUD APIs using Node.js
* Basic Python
* FastAPI fundamentals
* PostgreSQL basics
* JWT authentication

I am now starting my AI engineering journey.

---

# Learning Goal

I do **not** want to learn AI by reading interview-style theoretical concepts, definitions, or lengthy explanations first.

Instead, I want to **learn by building real enterprise AI features**.

My goal is to develop each feature from start to finish and understand how everything works by actually implementing it.

Once I complete all the features, I will go back and study each concept in depth from an interview and architecture perspective.

---

# Learning Strategy

We will build **one feature at a time**.

Each feature should be treated as an independent module.

There is **no requirement** that one feature must depend on another. If a dependency exists, keep it minimal.

The objective is that after completing a feature, I should be confident enough to build the same feature in any future application.

---

# Project

I will create a single web application called **Enterprise AI Learning Lab**.

The application will have a left-side navigation menu.

Each navigation item represents one AI capability.

For example:

* Dashboard
* AI Chat Assistant
* Document Processing
* Knowledge Center
* RAG
* Enterprise Search
* SQL Assistant
* API Intelligence
* AI Agents
* Workflow Automation
* Execution Monitoring
* Model Evaluation
* Administration

When I click a navigation item, the corresponding page should open, allowing me to use and test the feature that I have developed.

This application is primarily for learning, experimentation, and demonstrating enterprise AI capabilities.

---

# Development Approach

For every feature:

1. Explain the business problem it solves.
2. Explain why companies use this feature.
3. Explain where it is used in real-world applications.
4. Explain the overall implementation approach.
5. Design a simple but enterprise-style solution.
6. Build the feature step by step.
7. Build only what is needed for this feature.
8. Keep the implementation clean, modular, and production-oriented.
9. Integrate the completed feature into the Enterprise AI Learning Lab.
10. Once the feature is complete, move to the next one.

---

# During Development

Do **not** overwhelm me with large amounts of theory.

Introduce concepts naturally while implementing the feature.

For every new technology, library, or AI concept:

* Explain what it is.
* Explain why we are using it.
* Explain where it fits into the feature.
* Keep the explanation concise and practical.

Examples include:

* LangChain
* LangGraph
* Embeddings
* Vector Databases
* Prompt Templates
* Tool Calling
* Streaming
* Redis
* Background Jobs

The explanation should be just enough for me to continue implementing the feature confidently.

---

# Code Quality

Generate production-quality code using:

* Next.js
* React
* TypeScript
* Python
* FastAPI
* PostgreSQL

Follow clean architecture and industry best practices.

Keep the project modular and easy to understand.

---

# Learning Philosophy

Build first.

Understand the overall flow first.

Gain confidence through implementation.

After implementing all major AI capabilities, revisit each topic individually for deep learning and interview preparation.

---

# Starting Point

Let's begin with the first feature.

Guide me step by step.

Do not skip important implementation details, but also avoid unnecessary theory unless it directly helps me build the feature.
